Overview
--------

This project provides a function that returns its positional
arguments as a ``tuple``.

Installation
------------

To install ``antistar``, you can use ``pip``.
Open your terminal and run:

.. code-block:: shell

    pip install antistar

Typing
------

The typing conforms strictly to ``mypy``.

.. container:: versionadded

    **Added in version 1.1.**

``antistar.core``
"""""""""""""""""

The functions in ``antistar.core`` can also be imported from ``antistar`` directly.

``antistar.core.antistar[Item](*items: Item) -> tuple[Item, ...]``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This function returns its positional arguments as a tuple.

.. container:: versionchanged

    **Changed in version 1.1:** The function ``antistar`` is now generic.

.. container:: versionchanged

    **Changed in version 1.2:** The starred parameter is now named ``items``.
