Overview
--------

This project provides a function that returns its positional arguments as a ``tuple``.

Installation
-------------------

To install ``antistar``, you can use ``pip``.
Open your terminal and run:

.. code-block:: shell

    pip install antistar

Typing
------

The typing conforms (not strictly) to ``mypy``.

Features
--------

``antistar.antistar(*args: Any) -> tuple``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This function returns its positional arguments as a tuple.

``antistar.tests.test() -> unittest.TextTestResult``
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

This project can be tested through its test function.

.. code-block:: python

    import antistar.tests
    antistar.tests.test()
